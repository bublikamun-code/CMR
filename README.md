## ✅ Что исправлено

### Безопасность и производительность (Фазы 1-2)

1. **aria-live для уведомлений** — скринридер теперь озвучивает результаты сохранения и ошибки
   - `features.js`: два постоянных live-региона (polite/assertive)
   - Ошибки перебивают речь (`role="alert"`), успех — нет
   - **До:** немой контейнер, полная тишина для незрячего пользователя
   - **После:** WCAG 4.1.3 Status Messages выполнен

2. **Авто-версионирование статики** — конец плавающим багам "у меня работает, у тебя нет"
   - `tools/stamp_assets.py`: версия = первые 10 символов sha1 содержимого файла
   - **До:** `?v=30` (застрял) vs `?v=1785023000` (вручную), 25 ссылок разъехались
   - **После:** `?v=777c0dd4b1` (features.js), автоматическая синхронизация при каждом изменении

3. **Chart.js перенесён с CDN** в `js/vendor/`
   - **До:** единая точка отказа + риск подмены кода с доступом к токену в `localStorage`
   - **После:** 205 KB локально, полная автономность дашборда

4. **rel="noopener noreferrer"** на ссылки с `target="_blank"`
   - Закрыта утечка `window.opener` при переходе в админ-панель

5. **Поиск с debounce 200 мс** (`bindTableSearch` в `features.js`)
   - **До:** 4 таблицы вызывали `filterTableRows` на каждое нажатие клавиши
   - **После:** задержка 200 мс, ввод не отстаёт от клавиатуры на больших списках

6. **Таймаут запросов 30 с** + AbortController в `api.js`
   - **До:** `fetch` без таймаута — обрыв сети оставляет запрос висеть бесконечно
   - **После:** понятные сообщения вместо `AbortError` и голого `TypeError`

7. **Фикс залипающего опроса** в `realtime.js`
   - **До:** курсор в поле поиска навсегда блокировал обновление данных
   - **После:** блокируем опрос только при реально несохранённом вводе; простой >3 мин → событие `realtime:stale`

8. **Ложный комментарий про WebSocket** исправлен
   - **До:** `// Уведомления о новых сделках через WebSocket`
   - **Реальность:** polling каждые 15 с, никакого WebSocket нет

## 🔍 Что обнаружено (не исправлено)

### 🔴 КРИТИЧНО — требует немедленного патча (см. SECURITY.md)

1. **`POST /email-parser/sync-all` без аутентификации**
   - Любой может запустить массовую синхронизацию почты ВСЕХ арендаторов
   - Создание карточек от имени системы
   - DoS через многократный вызов

2. **IDOR на ~40 эндпоинтах**
   - Доступ к объектам других арендаторов по ID
   - Затронуты: clients, suppliers, cards, tags, webhooks, workflows, custom_objects
   - Проверяется только существование объекта, не `tenant_id`

3. **`.secret_key` закоммичен в git**
   - Компрометация JWT + расшифровка паролей от почты (Fernet использует тот же ключ)
   - Уже в истории репозитория — "разкоммитить" нельзя

### ⚠️ ВАЖНО

4. **GET /files/{filename}** — IDOR на файлах (любой авторизованный может скачать чужой файл, зная имя)
5. **Загрузка файлов** — проверка только расширения, не MIME-type
6. **Нет пагинации** в списочных эндпоинтах (DoS при >10 000 карточек)
7. **Rate limiting** только на `/login`, остальные эндпоинты открыты

### CSS — технический долг (7959 строк, см. отчёт агента)

- **1022 `!important`**, из них ~665 (56%) — борьба с собственным каскадом
- **792 хардкод-hex-цвета** против 881 `var(--)`
- **29 точных дублей** (91 строка) — селектор и тело идентичны
- **Топ-дублирующиеся селекторы:** `.data-table` 63 раза, `.kanban-card` 64, `.sidebar` 28
- **413 правил `[data-theme="dark"]`**, половина станет ненужной после замены хардкод-цветов на переменные
- **8 разных @media брейкпоинтов**, два блока `max-width: 900px` конфликтуют
- **Файл = хронологический журнал 23 слоёв** правок поверх базы (~3000 строк база, ~5000 наслоения)

### Доступность (a11y)

- **Канбан недоступен с клавиатуры** — drag-and-drop без клавиатурной альтернативы (WCAG 2.1.1)
- **29 из 39 полей без `<label>`** — опора на `placeholder`, который исчезает при вводе (WCAG 1.3.1 / 3.3.2)
- **61 inline `onclick=`** в HTML (смешение разметки и логики)
- **Дубли страниц:** `settings.html`, `workflows.html`, `custom_objects.html` дублируют секции `index.html`, на них никто не ссылается

### Архитектура фронтенда

- **Нет сборки** — 19 отдельных `<script>`, 247 KB несжатого CSS
- **Магазины/статусы зашиты** в HTML/CSS/JS (10+17+7 вхождений `"Матусевича"`, `"Богдановича"`, `"Новый запрос"`)
- **4 почти одинаковых CRUD-модуля** (payments/documents/clients/suppliers), но общие помощники уже вынесены в `features.js` — дублирование меньше, чем казалось в первичной оценке

## 🔧 Как использовать

### Автоматы

```bash
# Проверка синтаксиса JS
bash tools/check_js.sh

# Обновление версий статики (перед каждой выкладкой)
python3 tools/stamp_assets.py

# Проверка, что версии актуальны (для CI)
python3 tools/stamp_assets.py --check

# FTP (требует source .ftpenv)
source .ftpenv
python3 tools/ftp_sync.py ls                   # дерево сервера
python3 tools/ftp_sync.py pull site            # скачать в site/
python3 tools/ftp_sync.py push index.html js/api.js  # выгрузить файлы
python3 tools/ftp_sync.py rm old_file.bak      # удалить на сервере
```

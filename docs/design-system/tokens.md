# Токены

Источник значений — `:root` в `site/css/style.css` (единственный блок переменных,
светлая тема) и `[data-theme="dark"]` (тёмная). Ниже — канон и правила перевода
дрейфа в него.

## 1. Цвета

### Ядро (уже в `:root`)

| Группа | Токены |
|---|---|
| Акцент | `--primary-color` #4f46e5, `--primary-hover/--primary-dark/--primary-700` #4338ca, `--primary-500` #6366f1, `--primary-soft` #eef2ff, шкала `--primary-50/100/500/600/700` |
| Поверхности | `--bg-color` #f8fafc, `--bg-secondary` #f1f5f9, `--card-bg` #ffffff, `--sidebar-bg/-bg-2/-hover` |
| Текст | `--text-color` #1e293b, `--text-secondary` #334155, `--text-muted` #64748b, `--text-faint` = `--text-muted` |
| Семантика | `--danger-color` #dc2626, `--danger-dark` #b91c1c, `--success-color` #047857, `--warning-color` #b45309, `--info-bg` #e0f2fe |
| Границы | `--border-color` / `--border-light` #e2e8f0; тёмная тема добавляет `--border-interactive` |
| Магазины | `--store-matusevicha` #0369a1, `--store-bogdanovicha` #7c3aed, `--store-bn` #0f766e + `*-soft` |
| Таблица | `--table-header-bg/-text/-row-even/-row-odd/-row-hover` |

### Новые токены (добавляются в `:root`, значения = фактическим литералам)

Софт-триады для бейджей, алертов и плашек (фон / граница / текст):

```css
--danger-soft-bg: #fee2e2;   --danger-soft-border: #fecaca;  --danger-soft-text: #991b1b;
--success-soft-bg: #d1fae5;  --success-soft-border: #a7f3d0; --success-soft-text: #065f46;
--warning-soft-bg: #fef3c7;  --warning-soft-text: #92400e;
```

Приглушённая статусная шкала канбана (левая полоса карточек: «Сборка»/оплачен
/ просрочен / скоро срок) — сейчас захардкожена в style.css и liquid-glass.css:

```css
--status-success: #5aa98c;   /* сборка, оплачено */
--status-danger:  #c45a68;   /* просрочено */
--status-warning: #d4a373;   /* скоро срок */
--status-neutral: #94a3b8;   /* новый запрос / без статуса */
```

Фокус-кольцо и вспомогательные:

```css
--ring:        0 0 0 2px rgba(79, 70, 229, 0.10);  /* основное focus-кольцо */
--ring-strong: 0 0 0 3px rgba(79, 70, 229, 0.15);
--border-strong: #cbd5e1;    /* тёмная граница инпутов светлой темы */
--text-disabled: #94a3b8;    /* выключенный текст */
```

В `[data-theme="dark"]` новые токены НЕ переопределять, пока не понадобится:
существующие тёмные правила продолжают перекрывать их поточечно.

> **Легаси-семья `--soft-*`.** В style.css (блок ~строки 11156+, со своими
> тёмными значениями) уже существует другая семья мягких цветов:
> `--soft-success-bg/-text`, `--soft-warning-*`, `--soft-danger-*`,
> `--soft-info-*`, `--soft-muted-*` — с ДРУГИМИ значениями (#e8f5f0 vs
> #d1fae5 и т.п.). Использующие её компоненты не переводить на `--*-soft-*`
> и наоборот: слияние двух семей — отдельное дизайнерское решение, не
> механическая замена.

### Таблица «дрейф → канон» (цвета)

Проверено скриптом по style.css (значение → замена; «оставить» = литерал допустим):

| Дрейф | Замена | Примечание |
|---|---|---|
| `background: #fff` / `#ffffff` у поверхностей | `var(--card-bg)` | только фон поверхностей; `color: #fff` на тёмных фонах НЕ трогать |
| `#f1f5f9` | `var(--bg-secondary)` | |
| `#f8fafc` | `var(--bg-color)` | |
| `#eef1f6`, `#f4f7fb`, `#f3f4f6`, `#f9fafb` | ближайший из `--bg-color`/`--bg-secondary` | пять почти одинаковых серых → два |
| `#dc2626` | `var(--danger-color)` | |
| `#b91c1c` | `var(--danger-dark)` | |
| `#ef4444`, `#e5484d` | `var(--danger-color)` | красные дрейфуют, канон один |
| `#6b7280` | `var(--text-muted)` | gray-500 ≈ slate-500 |
| `#cbd5e1` | `var(--border-strong)` | токенизация без смены значения |
| `#94a3b8` (в светлой теме) | `var(--text-disabled)` | токенизация |
| `#fee2e2` / `#fecaca` / `#991b1b` | `--danger-soft-*` | |
| `#d1fae5` / `#a7f3d0` / `#065f46` | `--success-soft-*` | |
| `#fef3c7` / `#92400e` | `--warning-soft-*` | |
| `#5aa98c` / `#c45a68` / `#d4a373` | `--status-*` | и в style.css, и в liquid-glass.css |
| focus-тени `0 0 0 2px rgba(79,124,245,…)` | `var(--ring)` | чужой синий #4f7cf5 — ошибка, не наш индиго |
| `#10b981`, `#fbbf24`, `#2dd4bf` и т.п. | оставить | «яркие» ярусы для точек/графиков; канонизировать в отдельные токены при ≥3 новых местах |
| rgba-альфы liquid-glass.css | НЕ ТРОГАТЬ | это и есть дизайн стекла |

Палитра графиков/календаря (JS): `calendar.js` TYPE_* использует `#4f46e5`
(= `--primary-color` ✓), `#10b981`, `#ef4444` → в JS заменить `#ef4444` на
`#dc2626`; fallback-значения в `dashboard.js` (`#4a57a4`, `#10b981`) обновить до
фактических `#4f46e5` / `#047857`. Категорийные цвета чартов (`#f97316`,
`#ec4899`, `#a855f7`…) — легальны как дискретная палитра; держать их в одном
месте (`calendar.js` TYPE_* / константы дашборда), не плодить копии.

## 2. Типографика

Шрифт: Manrope (Google Fonts, 400–800), стек `--font-sans`. Допустимые шаги
кегля — **только целые из шкалы**:

```
10   мелкие счётчики/капсы        (--font-2xs)
11   бейджи, подписи, meta        (--font-xs)
12   плотные таблицы              (литерал 12px, разрешённый шаг)
13   таблицы, формы, тело UI      (--font-sm)
14   базовый, контролы            (--font-base)
16   заголовки страниц/секций     (--font-md)
18   акцентные заголовки          (литерал 18px, разрешённый шаг)
20   крупные цифры/статы          (--font-lg)
24   hero-статы дашборда          (литерал 24px, разрешённый шаг)
```

Слова-токены (`--font-xs/sm/base/md/lg`) — семантические имена для компонентов;
литералы 10/12/18/24 разрешены как утверждённые шаги шкалы. Дробные и
вне-шкальные значения запрещены.

| Дрейф | Замена | Вхождений |
|---|---|---|
| `10.5px` | `11px` | 9 |
| `11.5px` | `11px` | 9 |
| `12.5px` | `13px` | 5 |
| `13.5px` | `13px` | 5 |
| `15px` | `14px` | 18 |
| `17px` | `16px` | 1 |
| `22px` | `20px` | 2 |

## 3. Отступы

Сетка 4px: `4 / 8 / 12 / 16 / 20 / 24 / 32` (токены `--space-xs/sm/md/-/lg/-/xl`;
16 и 24 — литералы, разрешённые шаги). Два полу-шага для плотных контролов
и таблиц: `6px` и `10px`. Всё прочее — дрейф:

| Дрейф | Замена |
|---|---|
| `5px` | `4px` |
| `7px` | `8px` |
| `9px` | `8px` |
| `13px`, `14px`, `15px` (padding/gap) | `12px` или `16px` по контексту, ближе к соседям |

Массовую перенормировку паддингов не делать — только точки, попадающие в задачу
или явно случайные значения выше.

## 4. Радиусы

Канон: `--radius-sm` 6px (контролы, мелочь), `--radius-md` 10px (инпуты, меню,
карточки), `--radius-lg` 16px (модалки, контейнеры), `999px` (капсулы/пилюли),
`50%` (круг).

| Дрейф | Замена |
|---|---|
| `3px`, `4px`, `5px`, `6px` | `var(--radius-sm)` |
| `7px`, `8px`, `9px`, `10px`, `12px` | `var(--radius-md)` |
| `14px`, `16px`, `20px` | `var(--radius-lg)` |
| `99px` | `999px` |
| `2px` | оставить (единичные микро-случаи) |

## 5. Тени

Канон: `--shadow-sm` (плоские элементы), `--shadow-md` (карточки, ховеры),
`--shadow-lg` (модалки, дропдауны, тосты), плюс `--ring` / `--ring-strong` для
фокуса. Новых ручных `box-shadow` не создавать.

| Дрейф | Замена |
|---|---|
| `0 0 0 2px rgba(79, 70, 229, 0.08/0.10/0.12)` | `var(--ring)` |
| `0 0 0 2px rgba(79, 70, 229, 0.15)` / `0 0 0 3px … 0.15` | `var(--ring-strong)` |
| `0 0 0 2px rgba(79, 124, 245, 0.10/0.12)` | `var(--ring)` (чужой синий) |
| `0 1px 3px rgba(0,0,0,0.12)` | `var(--shadow-sm)` |
| `0 8px 20px rgba(15, 23, 42, 0.08)` | `var(--shadow-lg)` |
| прочие одиночные ручные тени | не трогать в этой итерации, заменять при ближайшем касании |

## 6. Переходы

`--transition-fast` 120ms / `--transition-normal` 200ms на `--ease-out-strong`,
готовые наборы `--transition-ui` / `--transition-ui-slow`. Существующие тайминги
анимаций выверены аудитом (docs/audits/UI_AUDIT_PLAN.md) — не «нормализовать» их;
для новых переходов использовать токены.

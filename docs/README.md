## Предупреждение по `phases/`

Документы в этой папке написаны до фактической проверки и местами расходятся
с действительностью. Приоритет всегда у [`../STATUS.md`](../STATUS.md).

Конкретно:

- **Phase 1 «завершена»** — на момент написания приложение через порт 80 не
  работало вообще. Реально закрыта 08.08.2026, см. `RESULT-2026-08-08.md`.
- **Phase 2, патч IDOR** — применять нельзя. Проверка
  `if card.tenant_id != current_user.tenant_id` при `tenant_id = NULL` у всех
  497 карточек даёт 403 на каждой. Изоляция арендаторов здесь реализована
  отдельными файлами БД, а не колонкой `tenant_id`.
- **Phase 3, очистка git от `.secret_key`** — не требуется, файла в истории
  никогда не было (`git log --all -- '*.secret_key'` → 0 коммитов).
- **Метрики** в этих файлах устарели: образы 320/93 MB (не 150/50), база
  1.7 MB (не 1.7 GB).

## Промпты

`prompts/project-context.md` — **симлинк** на `server_snapshot/PROMPT.md`,
контекст проекта для ИИ-ассистентов.

Оригинал остаётся рядом с кодом — он уходит на сервер вместе с бэкендом.
Симлинк вместо копии выбран сознательно: две копии неизбежно разошлись бы.
Правьте любой из путей — это один и тот же файл.

## P2-1. httpOnly-cookie вместо localStorage (XSS-устойчивость)
Сейчас украденный через XSS токен = полный доступ. Цель: токен в
`Set-Cookie: HttpOnly; Secure; SameSite=Lax`.

Шаги:
1. Бэкенд: после логина — Set-Cookie; оставить приём Authorization-заголовка
   на переходный период; эндпоинт /auth/logout чистит куку.
2. Фронт: убрать запись в localStorage, apiFetch ходит с `credentials: 'include'`.
3. Неделя на обкатку → удалить legacy-ветку.
Риск: CSRF — закрывается SameSite=Lax (у SPA все мутирующие запросы POST/PATCH
с same-origin). Проверка: логин/логаут/все вкладки; токен НЕ виден в
Application → Local Storage.
Оценка: 4–6 ч.

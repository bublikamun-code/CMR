- Миграции схемы: применённые migrate_*.py удалены из снапшота; схема БД живёт

## 3. Код (фронтенд)

- XSS: `escapeHtml`/`escAttr` используются при вставке данных (проверено
  точечно: writeoffs, contacts, kanban); `eval/new Function/document.write` —
  0 вхождений. CSP: `script-src 'self' 'unsafe-inline'` — unsafe-inline
  ослабляет CSP (нужны inline-хендлеры), риск остаточный, низкий.
- 401-обработка: единая в api.js (очистка токена, редирект на вход).
- Токен в localStorage — при XSS уводится; компенсируется CSP и эскейпом.
  Идеал — httpOnly cookie, но требует рефакторинга авторизации (бэклог).

## 7. ПЛАН Б (runbook)

Все команды от пользователя h212005 на сервере.

**A. Приложение упало / недоступно.**
1. `pm2 list` — если stopped: `pm2 restart crm`; watchdog сделает это сам за 5 мин.
2. Если порт занят («Address already in use»): подождать 10 с — PM2 перезапустит
   сам; проверить `curl -s http://127.0.0.1:20008/health`.

**B. Сервер перезагрузился.**
В течение 5 мин watchdog сделает `pm2 resurrect`. Ручной вариант:
`export NVM_DIR=$HOME/.nvm; . $NVM_DIR/nvm.sh; pm2 resurrect`.

**C. База повреждена / данные потеряны.**
```
pm2 stop crm
cp /var/www/h212005/data/crm_data/crm_app.db /tmp/crm_broken_$(date +%H%M).db
gunzip -c ~/backups/db_ПОСЛЕДНЯЯ.sqlite.gz > /var/www/h212005/data/crm_data/crm_app.db
rm -f /var/www/h212005/data/crm_data/crm_app.db-wal /var/www/h212005/data/crm_data/crm_app.db-shm
sqlite3 /var/www/h212005/data/crm_data/crm_app.db "PRAGMA integrity_check;"
pm2 start crm && curl -s http://127.0.0.1:20008/health
```
Дампы: `/var/www/h212005/data/backups/db_*.sqlite.gz` (ежедневно, 03:00,
хранение 14 дней). Потеря = время от последнего ночного дампа; до 24 ч.

**D. Удалены вложения (uploads).**
`tar -xzf ~/backups/uploads_ДАТА.tar.gz -C /var/www/h212005/data/crm_data/ --strip-components=?` —
проверить структуру архива тестовым списком `tar -tzf | head`.

**E. Неудачный деплой (фронт).**
`cd /var/www/h212005/data/www/cmr-svetvdome.online && ls ~/data/crm_backups_predeploy`
→ взять последний `backup_*`, скопировать из него `css/ js/ *.html` обратно.
История также в git (локально) — `git log --oneline site/`.

**F. Неудачный деплой (бэкенд).**
`bash /var/www/h212005/data/www/cmr-svetvdome.online/scripts/rollback.sh`
(откатывает .py из последнего pre-deploy бэкапа и рестартует PM2).

**G. Диск заполнился.**
Первые кандидаты: `~/backups/uploads_*.tar.gz` (284 МБ × копии),
`/var/www/h212005/data/archive/`, `~/.pm2/logs/*.log`.
`du -xh /var/www --max-depth=3 | sort -h | tail`.

**H. Секреты скомпрометированы.**
`.secret_key`: сгенерировать новый, `pm2 restart crm --update-env` — все JWT
станут невалидными (все перелогинятся). `.cron_token`: удалить файл, рестарт —
сгенерируется новый; обновить в кроне (строка notifications/sync-overdue).

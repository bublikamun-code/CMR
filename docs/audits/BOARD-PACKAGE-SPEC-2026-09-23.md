# Пакет следующего держателя board.js (после слияния worktree'ов 3 и 4) — 23.09

Одна сессия, атомарные коммиты по частям A–C, пересборка site-v2 одним
коммитом в конце (правило одной пересборки, V2-WORKPLAN «Параллелизация»,
правило 1). Перед стартом: `git worktree list` + `git status` в
`/private/tmp/crm-item3|4` — доски не должно быть среди чужих грязных файлов.

Источники: спека P0 `docs/audits/P0-HOTFIX-GROUP-ANNUL-SPEC-2026-09-23.md`
(части C и D, as-built контракт annul), реестр дефектов доски в
`V2-WORKPLAN-2026-09-22.md` (дефекты 2 и 7), сценарный прогон
`tools/v2_queue_scenario.py`.

## A. P0 часть C — клиентская отмена групповой ТН через серверный annul

`tools/mockups/shell-v2-board.js`, ветка отмены группы (`:1806-1843`):
вместо `apiMutate('annul-tx', { txId: group.serverTxId })` вызывать
`POST /writeoffs/groups/{group.serverId или id}/annul` (контракт: 200 —
размотанная группа, 403 не-админу, 404 нет группы, 400 «не закрыта
накладной»); `annul-tx` оставить фолбэком ТОЛЬКО для групп без `written_off`.
Тост строить из ответа сервера (детальный отчёт сервис наружу не отдаёт —
хватит факта успеха; при 400 «отменять нечего» тост не показывать, состояние
доразматывается сервером). Локальный `doCancelGroupLocal` остаётся как
зеркало ответа. Этим закрывается дефект 2 реестра (ложная кнопка после
перезагрузки): сервер теперь реально снимает `written_off` и возвращает
карточки из «Закрыто».

## B. P0 часть D — флаги групповых ТН из данных boot

`tools/mockups/shell-v2-prototype.html:1286` — строка группы в «Документах»
финансов собирается с `tnHere: false` и без `docTxId`; брать из
`KBData.groups` поля `docTxId`/`tnHere`/`billHere` (boot-шаблон отдаёт их с
`cafc5a9`). После правки галочка «ТН у нас» на групповой ТН сохраняется
(PATCH по docTxId) и читается после перезагрузки.

## C. Дефект 7 — деньги карточки после отмены одиночной ТН

`shell-v2-board.js` `doCancelLocal` (`:1848-1860`): вместо инвалидации
`remaining_kop = undefined; issued_total = undefined` пересчитывать локально:
`issued` = Σ сумм оставшихся docs (копейки), `issued_total = issued / 100`,
`remaining_kop = amount*100 − issued` (если `amount` карточки известен;
иначе оставить null и не менять семантику `hasRemaining(null)` — её фильтры
держат осознанно, см. комментарий `:96-98`). Ту же ревизию применить к
`doCancelGroupLocal` (`:1809-1826`): после серверного annul карточки группы
тоже остаются с инвалидированными деньгами. Критерий: прогон
`tools/v2_queue_scenario.py` — чек «после отмены карточка снова в очереди
«На списание»» PASS без ручной перезагрузки.

## Верификация пакета

1. `node --check` на правленых mockups (или jsc-проверка как в deploy.sh v2).
2. `CRM_USER=... CRM_PASS=... python3 tools/v2_queue_scenario.py` на стенде
   8126: все чеки PASS, включая дефект 7; скриншоты после отмены и обеих тем.
3. Перепись `tools/v2_error_census.py --base http://127.0.0.1:8126/v2/` —
   в свободное браузерное окно (правило 2 параллелизации): 0 pageerror,
   аномалии только известные артефакты стенда.
4. Скриншоты отмены групповой ТН (светлая/тёмная): до/после, тост из ответа.
5. В конце: `cd server_snapshot && python3 tools/build_site_v2.py` +
   `python3 tools/stamp_assets.py --check` (0 расхождений), коммит пересборки
   отдельным; деплой — решение владельца.

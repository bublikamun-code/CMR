🚀 LOCAL DEVELOPMENT (Docker)
──────────────────────────────────────────────────────────────────────────────
1. Start containers
   $ docker compose up -d

2. Check status
   $ docker ps
   $ docker compose logs -f backend

3. Open in browser
   http://localhost              (Frontend)
   http://localhost:8000         (Backend API)
   http://localhost:8000/health  (Health check)

4. Stop when done
   $ docker compose down


🚀 PRODUCTION DEPLOY (Bare-metal PM2 — ACTIVE)
──────────────────────────────────────────────────────────────────────────────
The live server (87.232.64.12, hoster.by) runs PM2, not Docker.

1. Deploy frontend (CSS/JS/HTML — no restart needed)
   $ tools/deploy.sh front

2. Deploy backend files (restarts PM2 process 'crm')
   $ tools/deploy.sh back main.py routers/clients_router.py

3. Operational commands
   $ tools/deploy.sh status     # PM2 process list
   $ tools/deploy.sh restart    # Restart only
   $ tools/deploy.sh logs 50    # Last 50 error-log lines
   $ tools/deploy.sh --dry-run front   # Preview

See docs/deployment/DEPLOYMENT.md for full details on both paths.

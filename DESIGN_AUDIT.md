# Аудит дизайна CRM «Свет в доме» (cmr-svetvdome.online)

Дата: 2026-08-25. Метод: живой обход интерфейса (Chrome, логин ManagerY, роль manager),
скриншоты состояний (default/hover/click/модалки), автоматический скан обрезанного текста,
разбор `css/style.css` (11 690 строк), `js/reveal.js`, `js/ui-polish.js`, HTML-страниц.

Скриншоты: `~/cmr-audit-shots/` (login, walk/*.png), сырые данные скана: `report.json`.

**Что сохраняем (нравится):** шрифтовая пара Manrope + Cormorant Garamond, тёмная тема,
набор SVG-иконок и a11y-доработки из `ui-polish.js`, токены отступов/типографики в `:root`.

## 1. Обрезанный текст — главная боль

Автоскан нашёл обрезания на 7 из 9 страниц: payments — 151 элемент, suppliers — 26,
documents — 21, kanban — 19, writeoffs — 14, clients — 6, dashboard — 3.

| Где | Что режется | Пример |
|---|---|---|
| Реестр оплат | Заголовки колонок чекбоксов и действий | «Про…», «Вып…», «Спи…», «При…», «Печать/довер…» |
| Реестр оплат | Суммы (!) и названия компаний | «1 275,31…», «Общество с ограничен…» |
| Реестр оплат | Кнопка-дропдаун печати и приоритет | «Печа…», «Дове…», «Не…» |
| Реестр оплат | Итоговая строка | «289 165,…» |
| Документы | Заголовки «№ накладной», «Накладная», «Счет», итог | «№ накладно…», «239 324,89 В…» |
| Канбан | Заголовки колонок | «В РА…», «ЖДЕТ О…», «СБОР…» |

Причины: узкие фиксированные колонки + `text-overflow: ellipsis` на `th` (заголовки
резать нельзя вообще), суммы в колонках фиксированной ширины без `tabular-nums`-раскладки,
кнопка «Печать/доверенность» с фиксированной шириной. Тултипы с полным текстом стоят только
на части элементов (`ui-polish.js` addTitles покрывает `.clickable-company`, `th`,
но не суммы, не кнопки, не заголовки колонок канбана).

## 2. Анимации — «дёргано и плавает»

- **Зоопарк таймингов:** в CSS 13+ вариантов длительности (0.1s, .12s, 0.15s, 150ms,
  180ms, 200ms, 0.2s, .25s, 220ms, 0.3s, 0.4s, 600ms, 1.1s) при уже заданных токенах
  `--transition-fast/normal`, которые используются непоследовательно.
- **Дубли keyframes:** `pageEnter` ×2 (стр. 462 и 5494), `cardSlideIn` ×2 (5391 и 11639,
  с разными параметрами — побеждает последний), `spin` ×2 (5030 и 10314).
- **Hover-lift везде:** `translateY(-1px/-2px)` на кнопках, карточках канбана, dash-stat,
  чипах календаря. Интерфейс «плывёт» под курсором, на тач-устройствах hover залипает.
- **Reveal-on-scroll** (`reveal.js`, классы `.reveal` на дашборде/канбане/настройках):
  контент «выезжает» при каждом переключении вкладок и обновлении — для рабочего
  инструмента это шум, а не польза.
- **Переанимация при перерисовке:** `cardSlideIn ... both` на `.kanban-card` — при любом
  обновлении данных доска «мигает» всей колодой; `pageEnter` на разделах — то же.
- **netBarPulse** — бесконечная пульсация полоски 1.1s, пока идёт запрос; при фоновых
  обновлениях (page-freshness) полоска дёргается регулярно.
- Вход модалок 250ms и выход 180ms — ок, это оставляем как базу.

## 3. Кнопки — нет системы

25+ классов `.btn-*`, собранных по мере роста фич. Несогласованно всё: высота, padding,
радиус (у primary/secondary `--radius-sm` = 4px — выглядит старо на фоне общих 8–12px),
цвет и поведение hover. Отдельные проблемы:

- `.btn-primary`: градиент + тень `rgba(79,124,245,.25)` — тень другого синего, не от
  `--primary-color #4a57a4`; hover = `filter: brightness` + lift.
- Кнопка «Печать/доверенность» в таблице — select-кнопка фиксированной ширины, текст
  режется («Печа…»).
- «Сбросить» (ghost), «99 старых» (dashed), «Выписать накладную» (outline), «Добавить»
  (solid), «Передать в сборку» (зелёный #1a9a75), «Админ-панель» (ярко-фиолетовый) —
  каждая со своим характером, палитра расползается.
- Иконочные кнопки (корзина, карандаш, «…») разного размера/прозрачности; «…» у
  поставщиков упирается в край таблицы.

## 4. Общий визуал

- **Палитра:** приглушённый `#4a57a4` рядом с яркими `#4338ca/#818cf8` (тени, градиенты,
  net-bar), розовым `--pink`, зелёным и фиолетовым акцентами — нет единого акцента.
- **Сайдбар:** круглая кнопка сворачивания «висит» на границе с контентом; нижние
  переключатели темы/плотности — две безликие тёмные плашки; заголовок «CRM Система»
  не связан с брендом на логине («CRM Свет в доме»).
- **Таблицы:** тёмная шапка `#0f172a` с белым текстом в светлой теме — тяжёлая;
  высота строк скачет (в «Документах» чипы «магазин+Печать» ставятся в столбик →
  строки в 2 раза выше, чем в «Оплатах»).
- **Пустоты:** белая полоса над таблицей поставщиков; дашборд — воронка занимает
  половину карточки, «137 Транзакций» переносится на вторую строку сетки; правая
  колонка модалки карточки — простыня пустоты.
- **Дефект на «Списании»:** жёлтый чип «Накладная не выписана» перекрывается кнопкой
  «Выписать накладную» (карточка «Рацио Домус»).
- **Логин:** аккуратно, но карточка простовата; serif-заголовок «Вход в CRM» — ок (шрифты нравятся).

## 5. План исправлений (только визуал, логика не трогается)

1. **Motion-система:** одна шкала (120/180/240ms) + один easing (`--ease-out-strong`);
   удалить дубли keyframes; убрать reveal и переанимацию карточек/разделов при обновлении
   данных (анимируем только первое появление); снять hover-lift, оставить тень/бордер;
   net-bar — без бесконечной пульсации.
2. **Кнопки:** единая система (primary / secondary / ghost / danger + размеры sm/md),
   радиус 8px, одинаковая высота; починить тень primary; «Печать/доверенность» —
   авторазмер с иконкой вместо резки текста.
3. **Таблицы/текст:** заголовки колонок не режутся (перенос или короткие подписи +
   title), суммы — `tabular-nums` и ширина по содержимому, тултипы на всё обрезанное,
   единая высота строк, светлая шапка таблиц в светлой теме.
4. **Визуальная чистка:** единый акцентный цвет; сайдбар (кнопка сворачивания, нижние
   тумблеры, админ-кнопка); убрать пустоты; фикс перекрытия чипа на «Списании».
5. **Проверка:** повторный обход скриптом, before/after-скриншоты, скан обрезаний → 0
   критичных; логика и данные не затрагиваются (правки только css + точечные классы в html/js).

# Расширенный аудит (UX / адаптивность / a11y / целостность)

- **Адаптивность:** 1920/1440/1280/1024/768/390 — горизонтального overflow страницы нет
  нигде; таблицы скроллятся внутри контейнера; мобильное меню работает.
- **A11y (axe-core, WCAG2 A/AA):** оплаты и дашборд — 0 нарушений; канбан — 1 serious,
  исправлен (tabindex). Контрасты и фокус-ловушки модалок — из ui-polish, сохранены.
- **UX:** потоки логин→разделы→модалка→Esc работают; дропдауны открываются; hover-отклик
  предсказуемый (тень, без сдвига); empty-states на месте. Кнопки, меняющие данные,
  намеренно не нажимались (продакшен).
- **Целостность:** радиус 8px, единое фокус-кольцо, шкала motion, hover=тень, светлые шапки
  таблиц, чипы в строку — применены везде; шрифты Manrope/Cormorant сохранены.

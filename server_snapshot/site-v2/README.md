# site-v2 — новый фронтенд (генерируется)

Собирается из прототипа `tools/mockups` командой:

    python3 tools/build_site_v2.py

Вручную не править: правки делаются в прототипе или в `tools/build_site_v2.py` (встроенные api.js/boot.js), затем пересборка.

Режимы: по умолчанию — CRM API (вход по учётке CRM); `?demo=1` — демо-данные.

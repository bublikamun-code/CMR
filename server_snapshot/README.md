# server_snapshot — снимок сервера

Этот каталог — зеркало реальной структуры bare-metal-сервера (бэкенд + фронтенд
рядом), снятое один раз для перехода на Docker.

## Важно

- **Бэкенд** (`*.py`, `requirements.txt`) — актуальный, именно он копируется
  в Docker-образ (`Dockerfile.backend`) и правится в ходе разработки.
- **Фронтенд** (`index.html`, `admin.html`, `js/`, `css/`, `static/`) здесь
  **устаревший одноразовый бэкап** и НЕ обновляется. Актуальный фронтенд —
  в [`../site/`](../site/): его собирает `Dockerfile.frontend`, туда вносятся
  все UI-правки, и по нему работает кеш-бастинг (`tools/stamp_assets.py`).

Не редактируйте фронтенд в этом каталоге — изменения не попадут ни в Docker,
ни в прод.
